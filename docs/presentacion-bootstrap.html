Bootstrap 5 en el dashboard
Guía práctica para el curso

Cómo funciona el framework, qué clases usamos en dashboard.html y cómo exponerlo con seguridad.

● Grid 12 columnas ● Navbar · Cards ● Utilidades m- / p-

Concepto

¿Qué es Bootstrap?

  • Framework de CSS (+ JS opcional) con clases con nombre fijo.
  • Evita escribir desde cero márgenes, colores, rejillas y tipografía.
  • Se carga por CDN en el <head>; sin ese enlace, las clases del proyecto no aplican.

Móvil primero

Meta viewport

<meta name="viewport" content="width=device-width, initial-scale=1" />

Indica al celular que use el ancho real del dispositivo. Así col-* puede apilarse bien. En dashboard.html va después de charset.

Ancho de lectura

container vs container-fluid

container

Centra el contenido y limita el ancho en pantallas grandes (más legible).

container-fluid

Casi todo el ancho útil — típico en dashboards “full width”.

Nosotros: navbar y main usan container + pb-5 en el main.

12 columnas

Sistema de rejilla

Siempre: padre row, hijos col-*. Los números suman hasta 12 por fila.

Prefijo Ancho mínimo típico
sm≥576px
md≥768px
lg≥992px
xl / xxl≥1200px / ≥1400px

col-6 col-md-3: en móvil mitad; desde md, cuarto de fila.

Aplicado · KPI

Indicadores en fila

<div class="row g-3 mb-4">
  <div class="col-6 col-md-3"> … </div>
</div>
  • Móvil: 2 tarjetas por fila (6+6).
  • Desde md: 4 tarjetas (3×4).
  • g-3 = espacio (gutter) entre columnas.

Aplicado · Gráficas

Dos columnas en escritorio

<div class="row g-4 mb-4">
  <div class="col-lg-6"> gráfica 1 </div>
  <div class="col-lg-6"> gráfica 2 </div>
</div>

Desde lg, dos gráficas por fila. En pantallas angostas se apilan. g-4 deja más aire entre tarjetas que en KPI.

Barra superior

Navbar + clases útiles

navbar · navbar-expand-lg
navbar-dark · bg-primary
mb-4 · shadow-sm
navbar-brand · ms-lg-auto

bg-primary en BS5 ≈ azul #0d6efd, igual línea visual que el panel.

Tarjetas

Cards en el dashboard

  • Hero: card + bg-primary bg-gradient + clase propia hero.
  • KPI: card metric + card-body.
  • Gráficas: card chart-card h-100 + card-header — h-100 iguala alturas en la fila.

Utilidades

Márgenes y relleno: m- / p-

mb-2, mb-4 — separar bloques.

py-4 — aire vertical en el hero.

pb-5 en <main> — no pegar el pie al borde.

Escala típica 0–5. Cambiar un número y recargar = ver el efecto sin tocar CSS custom.

JS + CSS propio

Bundle y <style>

bootstrap.bundle.min.js incluye Popper (dropdowns, tooltips…). En el panel actual casi todo es estático; cargarlo igual deja lista la base futura.

Tu CSS propio (.hero, .chart-card, gradiente de body) refina marca encima del esqueleto Bootstrap — buen argumento de UI en la exposición.

1 minuto

Checklist para exponer

  1. Bootstrap = clases → estilos predefinidos.
  2. Flujo layout: container → row → col-*.
  3. Responsive: combinar col-6 + col-md-3 (KPI).
  4. Componentes: navbar, card + utilidades.
  5. CDN + un poco de CSS del equipo = marca propia.
