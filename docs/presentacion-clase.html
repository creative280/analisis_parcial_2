Problema

¿Qué buscamos mostrar?

  • Entender patrones de solicitudes de visa registradas en el dataset institucional.
  • Pasar de un análisis en consola a un panel web compartible con el curso.
  • Cumplir el parcial: todas las gráficas + conclusión general debajo, con buena presentación.

Dataset

Fuente y columnas que usamos

Archivo data/Visa_Applications_Colombia_2017_20250217.xlsx cargado con Pandas.

Columnas normalizadas en código (analysis.py)
anio · nacionalidad · sexo · fecha_nacimiento · vocacion · numero

Las fechas se convierten con pd.to_datetime(..., dayfirst=True) para coherencia regional.

Stack

Tecnologías del proyecto

Backend y datos

  • Python 3
  • Pandas — lectura Excel y agregaciones
  • Matplotlib (Agg) — gráficas en el servidor sin ventana
  • Flask — ruta / y plantillas Jinja2

Frontend

  • Bootstrap 5 — grid, navbar, cards, KPI
  • Imágenes embebidas data:image/png;base64,...
  • CSS propio mínimo: radios, sombras, gradiente de fondo

Flujo

Cómo viaja la información

Excel → pandas (cargar_datos) → dashboard_service
Matplotlib → PNG en memoria → Base64 → Jinja (dashboard.html) → Navegador

Separación clara: src/ calcula; templates/ muestra; app.py conecta HTTP.

Entregable

Las cuatro visualizaciones en el dashboard

  1. Top 5 nacionalidades — barras (conteo de solicitudes).
  2. Solicitudes por año — línea temporal.
  3. Distribución por sexo — gráfico circular.
  4. Distribución de edades — histograma (edad estimada desde fecha de nacimiento).

Debajo: KPI (totales, periodo, edad media, año pico) y párrafo de conclusión general generado a partir de las métricas.

Ejecución

Cómo ver el proyecto en vivo

pip install -r requirements.txt
python app.py

Navegador: http://127.0.0.1:5000/

Opcional consola: cd src y python analysis.py para menú interactivo legado.

Mensaje final

Qué dejamos claro con el análisis

Combinamos dimensión geográfica (nacionalidad), temporal (año), demográfica (sexo y edad) y un texto de cierre que sintetiza cifras clave del dataset — para apoyar lectura ejecutiva y discusión en grupo.
