Solución en capas

Excel→ Pandas→ Matplotlib→ Base64→ HTML
  • Flask sirve la ruta / y une datos + plantilla.
  • Jinja2 rellena dashboard.html.
  • Bootstrap maqueta grid, navbar, cards y KPI.

Definición

¿Qué es Flask?

  • Microframework web para Python.
  • Servidor HTTP de desarrollo (puerto típico 5000): recibe petición, devuelve respuesta (HTML, JSON…).
  • Orden mental: URL → función Python → plantilla.

Organización

Cliente ↔ servidor

Qué pasa al abrir http://127.0.0.1:5000/

  1. El navegador envía GET a /.
  2. Flask ejecuta la función de la ruta (decorador @app.route).
  3. Se arma un diccionario de variables para la plantilla.
  4. render_template mezcla datos + HTML.
  5. El usuario ve la página ya terminada.

Código clave

app.py y **ctx

ctx = construir_contexto_dashboard(str(DATA_PATH))
return render_template("dashboard.html", **ctx)

El operador ** expande el diccionario como argumentos con nombre (stats, conclusion, imágenes…). Así la plantilla recibe todo sin listar campo a campo.

Plantillas

Jinja2: {{ }} y {% %}

<img src="{{ img_nacionalidades }}" alt="..." />

El valor ya llega como data:image/png;base64,... listo para el atributo src.

{% if ... %} evita mostrar números si faltan datos (ej. edad promedio).

Datos y gráficas

analysis + dashboard_service

  • cargar_datos: Excel → columnas limpias, fechas con dayfirst=True.
  • matplotlib.use("Agg"): sin ventana gráfica — adecuado al servidor.
  • PNG → Base64: imágenes en memoria; sin archivos temporales sueltos en disco.

Producto

KPI, conclusión y errores

  • KPI arriba: totales, periodo, edad media, año pico (formato miles).
  • texto_conclusion arma el párrafo final según métricas.

Si falta el Excel: respuesta 500 con mensaje claro — útil en desarrollo para ubicar el archivo en data/.

Examen / exposición

Qué decir en 1 minuto

  1. Flask = rutas + función + plantilla.
  2. La plantilla se completa en el servidor (no es HTML estático fijo).
  3. Bootstrap estructura; CSS propio refina detalle visual.
  4. Agg + Base64 = estadística en servidor → imagen embebida.
  5. Un solo cargar_datos comparte limpieza entre consola y web.
“Excel → Pandas → gráficas en memoria → Base64 → Jinja + Bootstrap → navegador.”
