1. ¿Qué es Bootstrap y qué hace en tu página?

Bootstrap es un framework de CSS (y un poco de JavaScript) que define clases con nombres fijos. Al usarlas en el HTML, el navegador aplica estilos predefinidos (márgenes, colores, rejilla, tipografía) sin escribir todo el CSS a mano.

  1. En el <head> enlazás el CSS por CDN.
  2. En el <body> usás clases como container, row, col-md-3, navbar, card.
  3. Bootstrap aplica estilos coherentes y responsive (se adaptan al ancho de pantalla).
Ejemplo mínimo
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet" />
<div class="container">
  <p class="text-primary fw-bold">Hola Bootstrap</p>
</div>
Aplicado en tu proyecto: en templates/dashboard.html, el <link> a Bootstrap desde cdn.jsdelivr.net habilita casi todas las clases del dashboard. Sin él, la UI pierde forma.

2. Meta viewport y móviles

Bootstrap asume que la página declara el ancho correcto en celulares:

<meta name="viewport" content="width=device-width, initial-scale=1" />

Indica al navegador usar el ancho real del dispositivo. Así las columnas col-* pueden apilarse bien. En tu dashboard.html va justo después de charset. Quitarlo puede provocar vista “miniaturizada” o zoom extraño.

3. Contenedores: container vs container-fluid

ClaseComportamiento típico
container Centra el contenido y deja márgenes laterales; no estira líneas de texto infinito en monitores anchos.
container-fluid Ocupa casi todo el ancho útil (útil en dashboards “full bleed”). 
<div class="container">
  <p>Contenido centrado con márgenes automáticos.</p>
</div>

Aplicado: el <nav> lleva un div.container para que el título no choque con los bordes. El <main class="container pb-5"> mantiene ancho legible; pb-5 es padding inferior grande (ver sección 7).

4. Sistema de rejilla (Grid)

Bootstrap divide el ancho en 12 columnas virtuales. Los hijos son col-* dentro de un row.

  • col-6 ≈ mitad (6/12).
  • col-12 ≈ ancho completo.
  • col-6 col-md-3: desde md (≥768px), cada hijo ocupa 3/12; en pantallas más chicas rige col-6.
PrefijoAncho mínimo aprox.
(base col-*)Extra small
sm≥576px
md≥768px
lg≥992px
xl≥1200px
xxl≥1400px
 
<div class="row">
  <div class="col-12 col-lg-6">Izquierda</div>
  <div class="col-12 col-lg-6">Derecha</div>
</div>
KPI en tu dashboard
<div class="row g-3 mb-4">
  <div class="col-6 col-md-3">...</div>
</div>

Móvil: 2 tarjetas por fila. Desde md: 4 por fila.

Gráficas
<div class="row g-4 mb-4">
  <div class="col-lg-6">...</div>
</div>

g-4 aumenta el hueco entre columnas (gutter).

6. Cards (tarjetas)

Agrupan borde, padding y opcionalmente cabecera y cuerpo.

<div class="card">
  <div class="card-header">Título arriba</div>
  <div class="card-body">Contenido</div>
</div>
  • h-100: igual altura entre tarjetas en la misma fila.
  • Hero del dashboard: card ... text-white bg-primary bg-gradient; la clase hero es CSS propio para radios/sombra.
  • KPI: card metric.
  • Gráficas: card chart-card h-100 + card-header + card-body text-center.

7. Utilidades de espaciado

Escala habitual 0–5. m = margin, p = padding; sufijos t b s e x y.

  • mb-2 / mb-4: separar bloques verticalmente.
  • py-4: padding vertical dentro del hero.
  • pb-5 en <main>: aire antes del pie.

Prueba cambiar g-3 a g-2 en KPI y recargar: verás el layout “respirar” sin tocar CSS custom.

9. Bordes, sombras y utilidades rápidas

border-top + pt-3 en el footer separan el cierre; text-center centra; bg-gradient mejora el hero sobre bg-primary.

10. JavaScript bootstrap.bundle.min.js

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Incluye Popper para dropdowns, tooltips, etc. En el dashboard actual no es obligatorio para el layout estático, pero deja lista la base si agregan componentes interactivos.

11. Tu CSS propio en <style>

Bootstrap cubre la mayor parte del esqueleto. Las clases .hero, .chart-card, .metric afinan radios, sombras y el gradiente de fondo para que no se vea “plantilla pelada”.

12. Checklist para exponer (1 minuto)

  1. Bootstrap = clases que activan CSS prearmado.
  2. Grid: container → row → col-* (hasta 12).
  3. Responsive: combinar col-6 col-md-3 como en KPI.
  4. Componentes: navbar, card + utilidades.
  5. CDN rápido; CSS propio corto para marca del equipo.
